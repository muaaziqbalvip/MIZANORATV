Mizanora TV — system kaise kaam karta hai

Mizanora TV ek self-hosted streaming system hai jo ek hi channel ke kai m3u8 servers me se har play par sabse kam latency wala server chunta hai. Sab kuch aapke control me hai: Firebase data, Vercel hosting, GitHub master playlist, aur ek private owner link.

Architecture

Browser / Player  (hls.js, TiviMate, Smarters, VLC)
        │
        │  /s/<signed>/index.m3u8     ← asli link kabhi expose nahi
        ▼
Vercel Serverless  ──────────────────────────────────────────
   api/stream.js   → fastest-source engine (parallel probe)
   api/proxy.js    → signed segment/key proxy (CORS + referer bypass)
   api/channels.js → public channel list (server-side Firebase)
   api/xtream/*    → Xtream Codes API (player_api / get / xmltv)
   api/github/*    → master.m3u publish (token server-side)
        │
        ├──► Firebase Firestore  (channels, settings, xtream_users, posts)
        └──► Upstream m3u8 servers (Server 1…N per channel)

Fastest-source engine (step by step)

  1. Parallel probe — channel ke saare servers ek sath check hote hain, 4 second timeout ke sath.
  2. Scoring — TTFB (ms) + priority penalty. Kam score = fastest.
  3. Manifest rewrite — jeetne wale server ka manifest fetch hota hai, har segment/key URI signed proxy me badal jata hai.
  4. Failover — stream beech me mar jaye to list ka agla alive server try hota hai.
  5. Cache — probe result 45 sec cache (warm lambda par instant response).
Sach baat: “6G speed” network/hardware ka feature hai — koi software ISP ki speed 6G nahi bana sakta. Jo Mizanora deta hai wo hai: sabse kam latency source, parallel probing, low-latency HLS settings, pre-buffer aur instant failover. Practically yahi “fastest” experience hai.

Xtream Codes API

  • /player_api.php?username=..&password=..&action=get_live_streams
  • /get.php?username=..&password=..&type=m3u_plus&output=m3u8
  • /xmltv.php?username=..&password=..
  • Stream URLs: /live/<user>/<pass>/<id>.m3u8 (fastest server par redirect)

Security model

  • Public site ko sirf signed short-lived links milte hain — raw m3u8 kabhi nahi.
  • Owner playlist: /m3u/<PLAYLIST_TOKEN> — token sirf Vercel env me.
  • Admin: Firebase Auth + Firestore rules; token server-side verify hota hai.
  • GitHub token browser ko kabhi nahi milta — sirf server-side API usay use karta hai.
